# Patrilines with Feedback

A small exploratory model accompanying the essay:

*Patrilines with Feedback; or, A Short Inquiry into the Y-Chromosome Bottleneck, Considered as a Control System.*

## Purpose

This repository contains a minimal simulation intended to explore whether
the observed reduction in Y-chromosome lineage diversity can arise from
the steady operation of coupled reproductive filters, rather than requiring
large-scale episodic events such as warfare.

The aim is not precise historical reconstruction, but structural demonstration.

## Structure

- `model/` — simulation code
- `data/` — extracted or reconstructed datasets
- `analysis/` — scripts for entropy and survival analysis
- `figures/` — generated plots
